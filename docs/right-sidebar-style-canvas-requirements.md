# 右侧侧边栏：样式 / 画布 — 功能需求（草案）

> 状态：待产品决策。结合 MindForge 现状列出可选项。  
> 目标：先定范围，再实现；未勾选的项默认不做。

---

## 1. 背景与目标

### 1.1 动机

MindForge 目前以顶部 Toolbar + Colour/Icon Tray 为主，**没有**节点 Inspector / 属性侧栏；节点持久化样式几乎只有 `color`。需要在右侧提供集中的样式与画布编辑入口。

### 1.2 目标（本需求覆盖）

1. 在编辑器右侧增加可开合的 **侧边工具栏**。
2. 提供两个 Tab：**样式**、**画布**。
3. 按 MindForge 现有模型与本地优先原则裁剪能力范围。

### 1.3 非目标（明确不做，除非另开需求）

| 项 | 原因 |
|----|------|
| Relationship / Boundary / Summary / Callout 样式 | MindForge 尚无对应图元 |
| 主题内富文本分段样式（选中部分文字改色） | 当前节点文本为纯文本 |
| 云端主题库 / 账号同步 | 违反 local-only |
| 完整复制全量形状库与线端样式 | 成本高，可分期 |

## 5. 数据与兼容性约束

1. 新增节点样式字段须进入 `MindMapTreeNode`，并保证 **mmforge 往返保真**（`roundTrip` 门禁加 mask）。
2. FreeMind / Freeplane / WiseMapping 导入：能映射的映射（如 `font`、`shape`、`bgColor`）；映射不了的静默忽略，不丢其他数据。
3. 导出：至少在 mmforge 完整保留；对外格式按现有能力增量（不必第一期全对齐）。
4. 所有样式变更进入 Undo/Redo 历史。
5. 不记录文档内容到日志；不引入云端主题同步。

## 6. 建议分期（供裁剪）

### MVP（建议最小可交付）— **已实现**

- 壳：S-01～S-03、S-06  
- 样式：STY-01、STY-10、STY-11、STY-13  
- 画布：C-01（设备本地）、C-02、C-30、C-31  

约等于：「右侧有样式/画布两个 Tab；能改填色与文字；能改背景与网格；布局入口进侧栏」。

入口：工具栏 **Format** 按钮（`Mod+Shift+3`）。开合与网格偏好写入 `mindforge-ui`。

### 增强一期 — **已实现**

- S-05、S-08  
- STY-02、STY-03、STY-20、STY-21、STY-31、STY-60  
- C-10、C-11（文档级 `colorThemeId`，渲染解析）、C-20、C-22、C-36、C-40  
  - C-13 覆盖开关已取消：主题不修改节点已有颜色

要点：选中节点自动切 Style Tab、点空白切 Canvas；形状/边框/分支线/左右侧；图标快捷格；文档级配色主题（按分支 index + 深度淡化，不写节点 `color`）；文档级默认字体与线色；Focus 与缩放控件。
### 增强二期 / 另议

- 多选混合态、批量 Update、Compact/Balance、自定义主题、多种 Skeleton、编号、富文本等。
